Unique Identifiers (UIDs) - Godot 4.6

What are UIDs?

UIDs are unique identifiers for resources that remain stable even if you rename or move files. This prevents broken references in your project.

# Loading resources with UID (recommended)
@export var player_scene: PackedScene  # Set in Inspector - uses UID automatically
@export var enemy_mesh: Mesh

# Traditional path-based loading (still works)
var scene = load("res://scenes/player.tscn")

# Loading with UID directly
var scene = load("uid://abc123def456")

# Getting UID of a resource
var uid = ResourceUID.id_to_text(ResourceLoader.get_resource_uid("res://player.tscn"))
print("UID: ", uid)
▶ 💡 Why UIDs Matter

UIDs prevent your game from breaking when you reorganize files. If you move "enemy.tscn" from "scenes/" to "scenes/enemies/", UID-based references keep resolving, because they point to the file's ID rather than its path.

Example: Safe Resource References
# Path-based reference - tied to the file's exact path
const ENEMY = preload("res://scenes/enemy.tscn")

# UID-based - use @export; the Inspector stores a uid:// reference
@export var enemy_scene: PackedScene

func spawn_enemy():
    var enemy = enemy_scene.instantiate()
    add_child(enemy)

# The Inspector stores it as uid://... internally
# Even if you rename enemy.tscn, the reference stays valid!

String Types & Node Paths

StringName (&)

Optimized String

Faster for comparisons and Dictionary keys. Slightly slower to create, but better for frequent lookups like Input actions or Signals.

if Input.is_action_just_pressed(&"jump"):
    print("Jumped!")
    
var weapons = { &"sword": 10, &"bow": 5 }

NodePath (^)

Pre-parsed Path

Used specifically for pointing to nodes or properties. Since it's pre-parsed, Godot doesn't spend time parsing the string during execution.

var path = ^"Player/Camera3D"
var camera = get_node(path)

# Often used with Tweens
tween.tween_property(self, ^"position:x", 10.0, 1.0)

Scene Unique Nodes (%)

Scene-Wide Access

Right-click a node in the scene tree and select "Access as Unique Name". You can then access it from any script in that same scene (unique names are scoped to the scene they're saved in) without needing the full path. Perfect for UI elements.

# Instead of full paths that break if you move nodes:

# Use a unique name (much safer):
@onready var health_bar = %HealthBar

    velocity = direction * speed
    look_at(player.global_position, Vector3.UP)
    move_and_slide()

var gravity = ProjectSettings.get_setting("physics/3d/default_gravity")

func _physics_process(delta):
    # Add gravity
    if not is_on_floor():
        velocity.y -= gravity * delta
    
    # Handle jump
    if Input.is_action_just_pressed("jump") and is_on_floor():
        velocity.y = jump_velocity
    
    # Get input direction (WASD/arrow keys)
    var input_dir = Input.get_vector("left", "right", "forward", "back")
    var direction = (transform.basis * Vector3(input_dir.x, 0, input_dir.y)).normalized()
    
    if direction:
        velocity.x = direction.x * speed
        velocity.z = direction.z * speed
    else:
        velocity.x = move_toward(velocity.x, 0, speed)
        velocity.z = move_toward(velocity.z, 0, speed)
    
    move_and_slide()

func can_see_target(target: Node3D, fov_degrees: float) -> bool:
    var to_target = (target.global_position - global_position).normalized()
    var forward = -global_transform.basis.z
    var dot = forward.dot(to_target)

Common Errors & Fixes

Null and freed nodes
  • Invalid access to property or key 'x' on a base object of type 'Nil' / Nonexistent function 'x' in base 'Nil'
    The variable is null: wrong node path (names are case-sensitive), or a plain var x = $Node ran before the node existed.
    Fix: use @onready, check names in the Scene dock, or print(x) to confirm it is null.
  • Node not found: 'Path'
    The path no longer matches the scene tree (node renamed or moved).
    Fix: use a Scene Unique Name (%Name) or an @export var node: Node assigned in the Inspector.
  • Nonexistent function 'x' in base 'previously freed'
    You kept a reference to a node that was freed (enemy died, scene changed).
    Fix: check is_instance_valid(node) before using it, and clear the reference when it dies.
Timing, signals and physics
  • Condition '!is_inside_tree()' is true
    Used global_position, global_transform or look_at() on a node that is not in the tree yet.
    Fix: call add_child() first, then set the global position.
  • Resumed function 'x()' after await, but class instance is gone
    A node awaited a timer, then was freed before it finished.
    Fix: await a signal owned by the node itself - a child Timer or create_tween().finished - so it is cleaned up with the node.
  • Can't change this state while flushing queries
    You changed collision shapes, monitoring or similar inside a physics callback such as body_entered.
    Fix: use set_deferred("disabled", true) or call_deferred().
  • Signal 'x' is already connected to given callable
    Connected the same signal twice (for example once in the editor and once in code).
    Fix: connect it in one place, or guard with is_connected().
  • Trying to assign an array of type "Array[Node]" to a variable of type "Array[Node3D]"
    Typed arrays do not convert automatically; get_nodes_in_group() returns Array[Node].
    Fix: use my_array.assign(get_tree().get_nodes_in_group("x")).

Scene Architecture & Communication

Call Down, Signal Up

The rule of thumb
  • Parent → child: call methods and set properties directly. The parent owns its children, so it can know about them.
  • Child → parent: emit a signal. A child should never reach up with get_parent(); it doesn't know who (if anyone) is listening.
  • Sibling → sibling: let the shared parent connect them.
  • Far apart: use a group or an autoload event bus (below).
# main.gd - the parent wires its children together
extends Node3D

@onready var player: Player = $Player
@onready var hud = $HUD

func _ready() -> void:
    player.health_changed.connect(hud.set_health)
    player.died.connect(_on_player_died)

# player.gd - the child only announces what happened
signal health_changed(current: int, maximum: int)
signal died

func take_damage(amount: int) -> void:
    health -= amount
    health_changed.emit(health, max_health)
    if health <= 0:
        died.emit()

# Avoid: the child reaches up and breaks if the tree changes
# get_parent().get_node("HUD").set_health(health)

Which Tool for Which Job?

Pick the lightest one that works
  • Signal: something happened and any number of nodes may care (damage taken, item collected, button pressed).
  • Direct call: you own the node and need a result back (parent calling a child's method).
  • @export var target: Node3D: a reference to something elsewhere in the scene, assigned in the Inspector instead of a fragile path.
  • Group: find or broadcast to many unrelated nodes (call_group("enemies", "alert"), get_nodes_in_group()).
  • Autoload: truly global services that outlive scenes (settings, save data, event bus, scene transitions). Not for per-level state.

Event bus tips
  • Signals disconnect automatically when the listening node is freed, so you rarely need to clean up.
  • Keep the bus for events many systems care about. A signal between a parent and its child does not need to go through it.

GPUParticles3D Essentials

The properties you will touch most
  • emitting - start or stop. one_shot - emit once, then stop (impacts, explosions).
  • explosiveness - 0 = steady stream, 1 = everything at once (a burst). amount and lifetime - how many particles and how long each lives.
  • process_material - a ParticleProcessMaterial that controls movement: direction, spread, velocity, gravity, scale, color over lifetime.
  • draw_pass_1 - the mesh each particle looks like. With no mesh, nothing is visible.
  • local_coords - off (default): particles stay in the world when the emitter moves. On: they follow the emitter.

Foliage Wind Shader (Spatial)

Texture Setup Required:
  • Wind Noise: Create a NoiseTexture2D.
  • Inside NoiseTexture settings: Set Seamless to On.
  • Inside FastNoiseLite settings: Set Frequency to ~0.02 for smooth, slow wind.

💡 Vertex Colors: This shader uses the Red Channel of vertex colors to mask wind strength (0 = stiff trunk, 1 = swaying leaves). 

shader_type spatial;

render_mode cull_disabled, depth_prepass_alpha, diffuse_burley, specular_disabled;

// Textures
uniform sampler2D albedo_texture : source_color;
uniform sampler2D normal_texture : hint_normal;
uniform sampler2D wind_noise : repeat_enable;

uniform float normal_strength : hint_range(0.0, 5.0) = 1.0;
uniform bool debug_vertex_colors = false;

group_uniforms Wind_Settings;
uniform float wind_speed : hint_range(0.0, 2.0) = 0.5;
uniform float wind_strength : hint_range(0.0, 5.0) = 0.5;
uniform float wind_direction_x : hint_range(-1.0, 1.0) = 1.0;
uniform float wind_direction_z : hint_range(-1.0, 1.0) = 0.5;
uniform float wind_scale : hint_range(0.0, 1.0) = 0.1;
uniform float wind_vertical_strength : hint_range(-1.0, 1.0) = 0.2;
uniform vec2 plant_offset = vec2(0.0, 0.0);
group_uniforms;

void vertex() {
    vec3 world_pos = (MODEL_MATRIX * vec4(VERTEX, 1.0)).xyz;
    vec2 wind_dir = normalize(vec2(wind_direction_x, wind_direction_z));
    vec2 noise_uv = (world_pos.xz * wind_scale) + plant_offset + (wind_dir * TIME * wind_speed);

    float noise_sample = texture(wind_noise, noise_uv).r;
    float displacement = (noise_sample - 0.5) * wind_strength;
    float mask = COLOR.r; // Red channel masks wind

    vec3 world_displacement = vec3(
        displacement * wind_dir.x * mask,
        displacement * wind_vertical_strength * mask,
        displacement * wind_dir.y * mask
    );

    VERTEX += (inverse(MODEL_MATRIX) * vec4(world_displacement, 0.0)).xyz;
}

void fragment() {
    vec4 color = texture(albedo_texture, UV);
    ALPHA = color.a;
    ALPHA_SCISSOR_THRESHOLD = 0.25;
    NORMAL_MAP = texture(normal_texture, UV).rgb;
    NORMAL_MAP_DEPTH = normal_strength;
    ALBEDO = color.rgb;

    if (debug_vertex_colors) {
        ALBEDO = vec3(COLOR.r, 0.0, 0.0);
        ALPHA = 1.0;
    }
}

uniform vec2 speed_1 = vec2(0.04, 0.01);

    // Scroll the noise layers
    vec2 uv_1 = UV * scale_1 + speed_1 * TIME;
    vec2 uv_2 = UV * scale_2 + speed_2 * TIME;
    
    float noise_a = texture(noise_texture, uv_1).r;
    float noise_b = texture(noise_texture, uv_2).r;
    float final_noise = mix(noise_a, noise_b, layer_mix);
    
    // Safe noise modulation for alpha
    float final_alpha = smoke.a * (1.0 - noise_influence * (1.0 - final_noise));
    final_alpha = max(final_alpha, 0.0);
    final_alpha *= overall_alpha;
    
    ALBEDO = albedo_tint.rgb;
    ALPHA = final_alpha;
    
    EMISSION = albedo_tint.rgb * emission_strength * final_noise;
}

// Helper Functions
vec3 N13(float p) {
    vec3 p3 = fract(vec3(p) * vec3(.1031,.11369,.13787));
    p3 += dot(p3, p3.yzx + 19.19);
    return fract(vec3((p3.x + p3.y)*p3.z, (p3.x+p3.z)*p3.y, (p3.y+p3.z)*p3.x));
}

float N(float t) {
    return fract(sin(t*12345.564)*7658.76);
}

float Saw(float b, float t) {
    return smoothstep(0.0, b, t)*smoothstep(1.0, b, t);
}

float sdEgg(in vec2 p, in float ra, in float rb) {
    const float k = sqrt(3.0);
    p.x = abs(p.x);
    float r = ra - rb;
    return ((p.y<0.0) ? length(vec2(p.x, p.y)) - r :
            (k*(p.x+r)<p.y) ? length(vec2(p.x, p.y-k*r)) :
            length(vec2(p.x+r,p.y)) - 2.0*r) - rb;
}

vec2 DropLayer2(vec2 uv, float t, vec2 densityScale) {
    uv.y = -uv.y;
    vec2 UV_original = uv;
    vec2 a = vec2(6.0, 1.0) * densityScale;
    vec2 grid = a*2.0;
    
    vec2 id = floor(uv * grid);
    float gridFall = N(id.x)/3.0 + 0.5;
    uv.y += t*gridFall/a.y;
    
    id = floor(uv * grid);
    float extraDropSpeed = N(id.x);
    uv.y += extraDropSpeed;
    
    id = floor(uv*grid);
    vec2 st = fract(uv*grid)-vec2(0.5, 0.0);
    vec3 n = N13(id.x*35.2+id.y*2376.1);
    
    float x = n.x-0.5;
    float lambda = UV_original.y * wiggle_frequency;
    
    float wiggle = sin(lambda+sin(lambda));
    x += wiggle*(0.5-abs(x))*(n.z-0.5) * wiggle_strength;
    x *= 0.6;
    
    float ti = fract(t*(gridFall+0.1)+n.z);
    float slowStart = 0.85;
    float y = (Saw(slowStart, ti)-0.5)*0.9+0.5;
    vec2 p = vec2(x, y);
    
    float dropShape = (ti > slowStart) ? -sin(TAU * ti/ (1.0-slowStart))*0.5 - 0.5 : 0.0;
    float d = sdEgg((st-p)*a.yx, 0.0, dropShape);
    
    float diameter = N(id.x+id.y)/7.0+0.2;
    float mainDrop = smoothstep(diameter / 1.5, 0.0, d);
    
    float r2 = smoothstep(1.0, y, st.y);
    float r = sqrt(r2);
    float cd = abs(st.x-x);
    float thickness = diameter * 0.95;
    
    float trail = smoothstep(thickness*r, 0.0, cd);
    float trailFront = smoothstep(-0.02, 0.02, st.y-y);
    trail *= r2*trailFront*0.5;
    
    float m = mainDrop + trail; 
    return vec2(m, trail);
}

float StaticDrops(vec2 uv, float t) {
    uv *= 40.0;
    vec2 id = floor(uv);
    vec2 center = StaticDropCenter(id)*0.6;
    vec3 rand = rand3(id);
    uv = fract(uv)-0.5;
    
    float d = length(uv-center.xy);
    float radius = 0.3;
    
    float drop = smoothstep(radius, 0.0, d);
    float fade = Saw(0.10, fract(t + rand.y));
    float intensity = fract(rand.x*27.0);
    
    drop *= fade * intensity;
    return drop;
}

vec2 Rain(vec2 input_uv, float t) {
    float staticDrops = smoothstep(-0.5, 1.0, rain_amount) * 2.0;
    float layer1 = smoothstep(0.25, 0.75, rain_amount);
    float layer2 = smoothstep(0.0, 0.5, rain_amount);
    
    float s = StaticDrops(input_uv, t) * staticDrops;
    vec2 m1 = DropLayer2(input_uv, t, vec2(1.0)) * layer1;
    vec2 m2 = DropLayer2(input_uv * 1.85, t, vec2(1.0)) * layer2;
    
    float c = s + m1.x + m2.x;
    c = smoothstep(0.3, 1.0, c);
    return vec2(c, max(m1.y, m2.y));
}

void fragment() {
    float iTime = TIME;
    vec2 iResolution = VIEWPORT_SIZE;
    vec2 uv = UV * uv_scale;
    float t = iTime * 0.2;
    
    vec2 c = Rain(uv, t);
    
    vec2 e = vec2(0.001, 0.0); 
    float cx = Rain(uv + vec2(e.x, 0.0), t).x;
    float cy = Rain(uv + vec2(0.0, e.x), t).x;
    vec2 n = vec2(cx - c.x, cy - c.x);
    
    vec2 screen_uv = SCREEN_UV;
    vec2 refracted_uv = screen_uv + n * refraction_strength * 0.5;
    refracted_uv = clamp(refracted_uv, 0.001, 0.999); 
    
    float maxBlur = mix(1.0, 4.0, rain_amount) * blur_size; 
    float minBlur = 0.0;
    float blur_amount = mix(maxBlur, minBlur, smoothstep(0.1, 0.6, c.x));
    
    vec4 col = textureLod(SCREEN_TEXTURE, refracted_uv, blur_amount);
    vec3 out_col = pow(col.rgb, vec3(1.0/1.7));
    
    vec3 lightDir = normalize(vec3(0.2, 1.0, 0.3));
    vec3 halfDir = normalize(lightDir + vec3(0.0, 0.0, 1.0));
    float spec = pow(max(dot(normalize(vec3(n, 1.0)), halfDir), 0.0), 32.0);
    out_col += spec * 0.5 * c.x;
    
    ALBEDO = out_col * brightness * mix(vec3(1.0), rain_tint.rgb, tint_strength);
    ALPHA = mix(col.a, 1.0, 0.6); 
    EMISSION = mix(vec3(0.0), ALBEDO, clamp(brightness - 1.0, 0.0, 1.0));
    ROUGHNESS = 0.05;
}
